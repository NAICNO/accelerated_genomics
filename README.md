
# NAIC Accelerated Genomics

## 1. `AUS/` (Active Development)

This directory contains ongoing work for the **Advanced User Support (AUS)** initiative.

* **Purpose:**
  * Develop accelerated germline and somatic NGS data processing pipelines
  * Develop GPU selection framework for NGS processing
* **Status:** In Active Development
* **Key Components:**
  * `configs/` – Configuration files and parameters.
  * `DOCs/` – Project documentation and usage guides.
  * `modules/` – NextFlow modules and other functional libraries.
* **Getting Started:** Refer to [`AUS/README.md`](./AUS/README.md) for environment setup, installation, and execution instructions.
